Fonte variável original, sem modificações, distribuída sob SIL Open Font License
1.1. O aviso de copyright e os termos completos acompanham o arquivo em OFL.txt.
Nenhum pacote npm ou carregamento por Google Fonts é necessário.

Geist atende a interface latina/PT-BR. A assinatura japonesa usa fontes do
sistema via `--usagi-font-ja`; não atribuir cobertura japonesa ao arquivo Geist.
`font-display: swap` e fontes de sistema mantêm a interface utilizável em caso
de falha no carregamento. Não foi criada logo ou fonte própria.
